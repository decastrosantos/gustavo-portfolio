    Hero case study

    The Legend of SQL

    Nullbane: The Query Keepers

    Where learning SQL becomes an adventure.

    The idea

    Practice is where SQL actually lives — and practice is usually a dry editor. Nullbane turns that practice into an RPG in the world of Datania, where the antagonist is Null.

    The concept

    Players travel kingdoms, take quests, face enemies and write real SQL against a live PostgreSQL database. The game is built for people who already know the basics and want to get dangerous with them — not a first lesson.

    What it holds

    One hundred levels, from beginner to expert. Three languages. Verifiable certificates. Progress, identity and permissions live in Supabase, with row-level security so each player only touches their own path.

    Craft

    SQL · PostgreSQL · Supabase · Game design · Educational technology · Product storytelling. AI helped accelerate the build. It did not invent the idea.
